# Quota Dashboard logo

- [Original supplied logo](../apps/web/public/brand/quota-dashboard-logo.png): preserved without changes, including the wordmark.
- [Transparent mark](../apps/web/public/brand/quota-mark.png): derived with the built-in ImageGen tool for the header, login entry points, and browser icon. The title remains live text so it follows the selected theme.
- `apps/web/components/BrandMark.tsx` shares the mark across the dashboard and login surfaces.

The final ImageGen edit prompt, with the original supplied image as its reference, was:

> Extract the original icon at the LEFT of this image as a polished, small app logo with genuine alpha transparency. Exact graphic: three smooth, slightly italic slanted rounded cards stacked down and right, front card mint/emerald green with a rounded horizontal transparent slot; middle card violet; back card green. Faithfully retain the supplied silhouette and proportions. Remove all text and the black canvas completely. Critical: absolutely clean vector-like edges, completely empty transparent negative spaces and outside background. No outlines, no cyan/green neon edge, no glow, no noise, no grunge, no shadow, no texture or extra pixels. Solid smooth green and violet fills with at most the original subtle color shading. The mark must look perfectly clean against white as well as charcoal. Center the single mark with a small 5% transparent margin. Icon only. Output an actual transparent PNG for immediate production use.
