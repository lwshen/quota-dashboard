# 配额与令牌兼容性更新

更新日期：2026-10-25。

## Kimi 配额

- 兼容比例配额与旧计数格式，支持周用量、会话配额和月总用量。
- 从 `window.duration` 和 `timeUnit` 读取实际时长，缺失或无效的时长不伪造。
- 比例与计数发生矛盾时，仅在周期时长相同、重置时间相近的情况下采用更高用量。
- 各窗口独立标记用量可信度，未知计数不显示为真实的零用量。
- 月总量未提供完整周期起点，不据此推算固定时长或用量节奏。

## Claude 模型周限额

- 遍历所有有效的 `weekly_scoped` 条目，即使其 `is_active` 为 `false` 也保留。
- 使用稳定的模型身份生成窗口 ID，跳过无效条目及 all-models 重复项。
- 模型切换和标签变化不会错误地触发跨配额重置比较。

## Codex 配额与 Credits

- 两个账户槽位均展示 Spark 的 5 小时与每周窗口，并按实际时长识别窗口。
- 余额使用原生 Credits 单位，零余额明确显示为 0。
- 支持根节点、速率限制节点和 spend controls 中的个人月额度。
- 同时展示月额度与独立购买余额，避免重复计算同一月额度剩余值。
- 工作区缺少可用月额度时，使用同一账户追加月用量查询，超时为 6 秒。
- 可选查询失败或未启用月限额时，保留已有主配额与余额。

## OAuth 续期

- Claude 和两个 Codex 槽位均支持字符串错误码、嵌套 `error.code` 及顶层 `code`。
- 永久失效的刷新凭据持久化为阻断状态，替换凭据后恢复。
- 网络故障与限流仍按原有策略退避重试。
- 保存轮换后的 token 和服务端提供的有效期，拒绝缺少有效 Access Token 的成功响应。

## 验证

- `pnpm test`：75 项离线 provider、OAuth、HTTP 传输和卡片渲染测试通过。
- `pnpm typecheck`：两个包的类型检查通过。
- `pnpm build`：生产构建通过。
- 未使用真实账户调用上游接口。

## 后续增强项

- 独立补全重置次数信息，可选查询失败时保留基本用量。
- 增加历史曲线和有数据依据的用量节奏提示，并设置历史数据保留策略。
- 抓取失败时保留同一账户的上次成功数据，同时展示数据时间和最新错误。
- 按实际需要增加适合服务端访问的 provider 数据源。
